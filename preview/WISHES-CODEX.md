# Пожелание из каталога: порядок работы для Codex

Браузер готовит текст поручения, пользователь читает его и отправляет в выбранный чат. Копирование не запускает работу и не меняет состояние пожелания. Поручение содержит номер, название, путь к карточке и локальным данным. Всегда перечитывай саму карточку: текст в ранее скопированном запросе может устареть.

## Одна карточка на весь путь

1. Найди существующую карточку по номеру и названию. Прочитай исходную формулировку, комментарии и результаты. Если путь этой машины недоступен, найди `documentation_root` в настройках личного skill-catalog; не создавай ещё одну карточку с тем же номером.
2. Определи нужный проект и ожидаемый результат. Не угадывай папку. Для уже проверенного пожелания учти сделанное и уточни новое поручение, если его нет.
3. При начале согласованной работы обнови состояние на «В работе». Исходные слова не переписывай.
4. Выполни задачу в её проекте. В конце допиши датированный комментарий: действия, проверки, результат, существующие ссылки, ограничения и следующий шаг. «Проверено» означает фактический результат, а не обещание или только сохранение текста. Функциональная проверка не подменяет приёмку владельцем.
5. Сохраняй через общий механизм ниже: он обновляет карточку, строку «Бэклога навыков» и историю. Простая правка Markdown вручную не создаёт событие истории. Перечитай результат после записи. В браузере пользователь увидит его после «Обновить список».

## Обновление через существующий механизм

Используй Python 3.12+. Модуль `backlog.py` лежит рядом с этой инструкцией, в исходниках — в `preview/`, в установленном комплекте — в `overview/`. Пути рабочей папки и исходных данных берутся из поручения, а не из примера ниже. Ничего не устанавливай только ради чтения карточки.

```python
import sys, json
from pathlib import Path

# Подставь проверенные пути из поручения и путь к этой инструкции.
module_directory = Path("ПАПКА_ЭТОЙ_ИНСТРУКЦИИ")
work = Path("РАБОЧИЕ_ДАННЫЕ_КАТАЛОГА")
source = Path("ИСХОДНЫЕ_ДАННЫЕ_КАТАЛОГА")
sys.path.insert(0, str(module_directory))
from backlog import Backlog

settings_path = work / "settings.json"
settings = json.loads(settings_path.read_text("utf-8-sig")) if settings_path.is_file() else {}
settings["source_data"] = str(source)
backlog = Backlog(settings, work)
key = "BK-ГОД-НОМЕР"  # существующий номер из поручения
document = backlog.handle({"action": "read", "id": key})
print(document["markdown"])

# После выполненной работы перечитай документ и сопоставь с прочитанным ранее.
# Если есть чужие изменения, сохрани их и пересмотри комментарий.
fresh = backlog.handle({"action": "read", "id": key})
if fresh["revision"] != document["revision"]:
    raise RuntimeError("Карточка изменилась: сначала прочитай свежий текст и пересмотри запись")
result = backlog.handle({
    "action": "update", "id": key, "revision": fresh["revision"],
    "state": "В работе",  # или «Проверено» после фактических проверок
    "comment": "Датированный фактический результат, проверки и ограничения",
    "next_step": "Конкретный оставшийся шаг",
})
print(backlog.handle({"action": "read", "id": key})["markdown"])
```

При конфликте версии не обходи защиту: перечитай карточку и согласуй свою запись с новым содержимым. Если диск с документами недоступен, сообщи, что результат пока не сохранён. Не объявляй запись успешной только по тексту ответа в чате.
