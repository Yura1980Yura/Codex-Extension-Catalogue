# Каталог 3.1 — текущая редакция

Принята пользователем как актуальная редакция 28.10.2026. Старый интерфейс в `app/manager/` сохранён как история. Название папки `preview/` сохранено для совместимости. Личные записи хранятся в `.local/catalog-current/`.

## Решение

- Весь Codex и проекты — равноправные области в левой панели.
- Одна надстройка объединяет подтверждённые составные части. Связанный ресурс не считается автоматически частью надстройки.
- Типы пересекаются: надстройка с навыком и MCP видна в обоих фильтрах. Несколько выбранных типов требуют наличия каждого типа. Область, состояние, направление, происхождение и теги пересекаются с ними.
- Проект наследует общие установки и показывает собственные. Назначение из заметок не является установкой.
- Состояние и область показаны отдельно для каждой части. Файл, настройка, обнаружение в Codex и проверка работы различаются.
- Описания, инструкции, авторы, расходы, ограничения, связи, заметки и история прежнего каталога доступны в правой панели.

## Визуальное решение

Сохраняется спокойная зелёная палитра мастерской: зелёный #20594d, чернильный #20332e, серый #65716d, фон #f5f7f6, белый #ffffff, янтарный #855b15. Шрифт Segoe UI Variable / Segoe UI — локальный, читаемый по-русски. Левое выравнивание; 232 px на проекты, гибкая сетка в центре, раскрывающаяся карточка 600 px справа. Никакого рекламного первого экрана: сразу перечень установленных надстроек.

Схема: `[Весь Codex / проекты / заметки] [Название области → фильтры → карточки] [Состав и сведения по выбору]`.

Проверка замысла: рекомендация дизайн-справочника Feature-Rich Showcase относится к рекламе и отклонена. Сохранены спокойные поверхности, чёткая иерархия и короткий отклик. Главный акцент — понятный состав каждой надстройки, а не счётчик или поисковая строка.

## Запуск

Python 3.12+: `python -X utf8 -B preview/server.py --open`.

При первом запуске программа определяет установленный каталог через installation.json. Список дополнительных папок проектов и снимок метаданных текущего чата можно передать в локальном файле `--settings`. Веб-сервер слушает только 127.0.0.1, по умолчанию порт 8772. Кнопка «Сверить с Codex» обновляет отдельный снимок. Отображается время каждого источника.

Личные заметки, избранное, теги и пожелания сохраняются отдельно. Включение и отключение поддерживается для личных глобальных навыков, пользовательских MCP и плагинов, подтверждённых приложений аккаунта. Переключение дописывается в общую историю без изменения старых событий. Системные и проектные части, управляемые пакеты и неподтверждённые установки сопровождаются объяснением вместо переключателя. Новая версия не отправляет запросы в Meshy и другие генераторы.

Полнота ограничена доступными интерфейсами Codex и зарегистрированными папками. Снимок одного чата не является непрерывным наблюдением за всеми чатами. Локальные программы обнаруживаются только по явно указанным существующим исполняемым файлам; это не аудит всех установленных программ Windows.
