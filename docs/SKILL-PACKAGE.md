# Описание навыка из его пакета

Карточка может получать пользовательское название и стартовый вызов из стандартного `agents/openai.yaml`: `interface.display_name` и `interface.default_prompt`. Промпт должен явно содержать `$имя-навыка`. Копирование использует ID выбранной установки, поэтому одноимённая копия другого проекта не подменяет вызов. Без метаданных сохраняется прежний общий вызов.

Дополнительные сведения лежат рядом с SKILL.md в необязательном catalog.json:

```json
{
  "schema": 1,
  "name": "example-skill",
  "title_ru": "Понятное название",
  "version": "1.0.0",
  "instruction_language": "ru",
  "source": {
    "author": "Автор",
    "repository": "owner/library",
    "url": "https://github.com/owner/library/tree/main/skills/example-skill"
  },
  "helps": "Для чего нужен навык",
  "output": "Какой результат получает пользователь",
  "choose_when": "Когда применять",
  "prepare": "Какие сведения подготовить",
  "dependencies": "Реальные зависимости и необходимые доступы",
  "portability": "portable",
  "capability_groups": [{"title": "Возможность", "text": "Описание"}],
  "capability_limits": "Ограничения",
  "documentation": [{"id": "README.md", "title": "Как пользоваться"}]
}
```

Русский оригинал с `instruction_language: ru` читается прямо из активного SKILL.md и не требует дублирования в реестре переводов. Для переводов других инструкций сохраняются проверки соответствия исходнику. Указание языка — декларация пакета.

Документы открываются внутри читателя каталога. Разрешены только существующие MD/TXT внутри выбранной папки навыка: абсолютные пути, выход через `..` и ссылки за пределы пакета не принимаются. Ограничения размера: 64 КиБ метаданных, 512 КиБ документа и 2 МиБ совокупно на пакет. Если описания документов нет, может быть предложен существующий README.md.

Метаданные не назначают installed/enabled, область или разрешения: эти поля берутся из Codex и фактических путей. Заявление пакета о происхождении от OpenAI не принимается. Пользовательские подтверждения автора, происхождения и описаний сохраняют приоритет. Ошибка необязательных метаданных не скрывает сам SKILL.md.
