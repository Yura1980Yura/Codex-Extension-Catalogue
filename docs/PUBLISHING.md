# Публикация Codex Extension Catalogue

Выпуск 3.6.1 подготовлен для распространения из текущего репозитория. Стабильный комплект включает Codex-Extension-Catalogue.zip, START-CODEX.txt и SHA256SUMS.txt.

Перед публикацией проверяются все достижимые Git-объекты и текущие файлы: ключи OpenAI/GitHub/Meshy, Bearer-секреты, приватные ключи и AWS, чувствительные имена файлов. На исходной истории проверены 308 blob-объектов; два совпадения в tests/test_connections.py — алфавитные тестовые строки, не действующие ключи. Профилей Codex, auth.json, config.toml, пользовательских снимков и журналов в истории не обнаружено. Это результат проверки конкретного выпуска, не гарантия для будущих коммитов.

Репозиторий содержит только исходники, тесты, документацию, шаблоны и справочные описания возможностей. Лицензии сторонних поставок сохранены. Личные данные находятся вне комплекта. Из новых общих метаданных убрана привязка к проекту владельца; в старой истории остаются названия и ссылки из справочных описаний, без содержимого проектов и учётных данных.

Порядок: проверки → manifest → сборка → установка из распакованного ZIP в отдельный профиль → проверка ярлыка и API → commit/push/tag → изменение видимости → Release → проверка публичного доступа и SHA-256 скачанного архива.

При будущих выпусках повторяйте проверку текущего дерева и новых достижимых объектов. Не публикуйте .local, данные профиля, API-ключи, дампы конфигурации, пользовательские инструкции и историю чатов. Не переписывайте историю ради косметики; находка реального секрета требует отдельного разбора, отзыва ключа и согласованной очистки истории до публикации.
