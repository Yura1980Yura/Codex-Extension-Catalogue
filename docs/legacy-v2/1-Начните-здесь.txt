НАВЫКИ — пробный комплект для Windows
Версия комплекта: 24.10.2026

Это личная библиотека инструкций для Codex. У неё два входа:
браузерное окно для просмотра, заметок и управления; чат Codex для подбора,
исследования, установки выбранных навыков и выполнения вашей задачи.

ПЕРВЫЙ ЗАПУСК — ЧЕТЫРЕ ШАГА

1. Установите официальное приложение Codex и войдите в свой аккаунт.
   Актуальная инструкция OpenAI: https://learn.chatgpt.com/docs/quickstart
   Вход в аккаунт и условия доступа выполняются вами, отдельно от каталога.

2. Распакуйте присланный ZIP через «Извлечь всё», например в папку
   «Документы\Naviki-Package». Не запускайте файлы прямо внутри ZIP.

3. Откройте эту распакованную папку как проект в Codex.
   Откройте файл «2-Промпт-для-Codex.txt», скопируйте его целиком
   и отправьте в новый чат Codex в этой папке.

4. Codex проверит комплект, найдёт Python, выполнит setup.py и откроет
   браузерный каталог. Если нужной программы нет, он объяснит следующий шаг.
   Для подключения каталога во всех новых чатах перезапустите Codex.

ПОВТОРНЫЙ ЗАПУСК

Откройте «Документы\Naviki\Открыть каталог.cmd» двойным щелчком.
Можно создать для этого файла обычный ярлык на рабочем столе.
Либо попросите в Codex: «Открой мой каталог навыков».
Закрытие вкладки оставляет локальный менеджер запущенным.
Остановить его можно через «Как пользоваться → Завершить работу менеджера».

КАК ПОНЯТЬ, ЧТО ВСЁ РАБОТАЕТ

В браузере есть пять разделов: «Мои навыки», «Проекты», «Найти новые»,
«Блокнот», «История». Откройте карточку «Каталог навыков» и её русскую
инструкцию. Запишите свою первую заметку, откройте карточку заново.
В новом чате Codex напишите: «Покажи мой каталог навыков».

У вас будет собственный список. Число навыков не обязано совпадать со
списком человека, который прислал архив. Чужие навыки, заметки, проекты,
аккаунты и история в комплект не входят. Необходимые навыки можно найти
и установить отдельно через Codex.

ЧТО НУЖНО

Windows, установленный Codex и доступ к работе в нём, Python 3.12 или новее,
обычный браузер. Готовый Python часто уже доступен Codex; отдельная установка
может не понадобиться. Node.js, Git, Obsidian и доступ к репозиторию автора
для запуска каталога не требуются. Интернет нужен для установки недостающих
программ, сетевого поиска и работы Codex; локальный просмотр заметок может
работать без интернета.

ГДЕ БУДУТ ВАШИ ДАННЫЕ

Программа: папка пользователя\Applications\Naviki.
Навык Codex: папка пользователя\.agents\skills\skill-catalog.
Личные данные: папка пользователя\.codex\skill-catalog.
Заметки: Документы\Naviki\Projects\Catalog.
Сервер доступен только на вашем компьютере; адрес обычно http://127.0.0.1:8768.
Если порт занят, программа выбирает другой и открывает его сама.

Сохраняйте резерв папки личных данных и папки заметок. Исходный ZIP является
копией программы, но не резервом появившихся после установки заметок.

ПЕРЕД УСТАНОВКОЙ ПОВЕРХ СУЩЕСТВУЮЩЕГО КАТАЛОГА

Этот комплект предназначен для первой пробной установки. Если каталог уже
существует, установщик остановится и сохранит прежние данные. Попросите
Codex сначала проверить совместимость и подготовить резерв. Автоматической
замены другого каталога или автоматического обновления программы здесь нет.

ПОДРОБНОСТИ

«3-Возможности-и-ограничения.md» — полная инструкция.
«Инструкция.html» — та же инструкция для обычного браузера.
MANIFEST.json — список файлов и их контрольные суммы для проверки целостности.
Комплект не содержит Codex и не предоставляет аккаунт или подписку OpenAI.
