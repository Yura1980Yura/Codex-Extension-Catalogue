# Что умеет каталог 3.1

Выберите «Весь Codex» или проект слева. Откройте карточку: она объясняет назначение надстройки, её состав и область. Навык — инструкция; MCP — подключение инструментов; плагин — комплект; приложение — сервис аккаунта; программа — найденное приложение Windows. Одна надстройка может содержать несколько таких частей.

## Уже работает

- Обзор установок, включения и оснований проверки для каждой части.
- Переключатель «Использовать в Codex» в обзоре и составе карточки. После записи каталог перечитывает настройку; успешное изменение появляется в истории.
- Для личных глобальных навыков — прежний проверенный механизм. Для MCP и плагинов — пользовательская настройка включения. Для подтверждённых приложений аккаунта — разрешение использовать их в Codex на этом компьютере, без отключения аккаунта.
- Общие и локальные установки в проекте; названия основных папок из Codex.
- Пересекающиеся фильтры и несколько галочек внутри списков.
- Собственный порядок карточек в каждой области, перетаскивание и клавиатура.
- Заметки, теги, избранное, пожелания, история и чтение прежних записей.
- Читаемые инструкции с таблицами; русская копия, когда она соответствует оригиналу; копирование вызова.
- Открытие папки проекта; подробный перечень того, что даёт каждая его надстройка.
- Автоматическая сверка местных изменений с интервалом 15 секунд и приложений аккаунта каждые пять минут, ручная сверка и дата результата.
- Автоматическое сопоставление обнаруженных частей с карточками: пропуски и повторы показываются в «Откуда эти сведения».

## Чего пока нет

Каталог не устанавливает и не удаляет надстройки; не меняет разрешения и не запускает задачу по нажатию «Скопировать вызов». У прежнего интерфейса остаются его поддерживаемые операции; он сохранён по ссылке внизу боковой панели.

Нет непрерывного наблюдения за всеми чатами, чужими компьютерами и неизвестными папками. Наличие приложения аккаунта не доказывает успешную операцию в сервисе. Назначение проекта и физическая область установки различаются: глобально сохранённый навык может предписывать работу только с одной игрой.

Поиск и установка новых навыков по вашей задаче выполняются через Codex с личным навыком skill-catalog. Браузер помогает понимать и организовывать то, что у вас есть.

Meshy не запускается проверкой каталога. Для платных действий требуется отдельное явное поручение, согласованная задача, число вариантов, модель и лимит кредитов. Ключи не входят в каталог или экспорт.

## Включение и запуск

После переключения требуется перезапуск Codex: уже открытый чат не выгружает инструкции мгновенно. Каталог сразу показывает сохранённую настройку. Глобальное изменение относится ко всем проектам без собственного переопределения. Локальные и системные установки здесь не переписываются; причина указана у соответствующей части.

Ссылки 8770 и 8771 автоматически открывают текущий каталог на 8772. Повторный запуск ярлыка обновляет устаревший сервер на том же адресе. Если файл страницы не загрузился, появляется объяснение и кнопка «Повторить загрузку» вместо бесконечного вращения.
