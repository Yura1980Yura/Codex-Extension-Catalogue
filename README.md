# Навыки — каталог Codex 3.3

**Актуальная редакция с 28 октября 2026 года.** Обзор всего Codex и отдельных проектов: что установлено, для чего нужно, из каких частей состоит, что глобальное и что локальное.

## Запуск

Из этой папки: `python -X utf8 -B launch.py`. Нужны Windows, Python 3.12+ и установленный Codex. Сайт открывается только на вашем компьютере: по умолчанию `http://127.0.0.1:8772`.

Для первой установки из полного комплекта: `python -X utf8 -B setup.py --verify-only`, затем `python -X utf8 -B setup.py`. Повторное открытие — «Документы → Naviki → Открыть каталог.cmd». Установщик сохраняет прежнюю установку, если она уже изменена: обновлять её вслепую нельзя. На компьютере с прежним каталогом новую редакцию можно открыть из исходников командой выше.

## Как пользоваться

- «Весь Codex» — все обнаруженные надстройки. Проект слева — общие установки плюс его локальные.
- Карточка содержит смысл, состав, область, включение, инструкции, расходы, источники, заметки и опыт. «Установлено» не означает «успешно испытано».
- Фильтры можно сочетать. Галочки внутри одного списка означают «любой из выбранных». Одновременно выбранные типы требуют всех этих частей: «Навык + MCP» оставляет составные надстройки.
- «Мой порядок» позволяет менять любые две карточки местами: перетащите ручку одной на другую плитку. Остальные позиции сохраняются. Кнопки ↑/↓ и Alt+стрелки меняют местами соседние видимые карточки. Порядок хранится отдельно для всего Codex и каждой папки.
- Инструкции читаются с заголовками, таблицами и списками. Вызов можно скопировать прямо из окна чтения; копирование не запускает задачу.
- «Настройки проекта» открывают существующие настройки сразу с выбранным проектом. У путей навыков есть действия для открытия папки и копирования пути.
- Прежний каталог сохранён как история. Единственная ссылка на него находится внизу боковой панели; она запускает его при необходимости.

## Включение надстроек

В карточке откройте «Использовать в Codex». Переключатели доступны и в «Составе». Изменение подтверждается чтением настройки и сохраняется в общей истории. Перезапустите Codex для применения в открытых чатах. Глобальные настройки наследуются проектами; отдельные проектные или управляемые настройки не заменяются.

Ссылки прежних запусков на портах 8770 и 8771 перенаправляются на текущий каталог. Повторный запуск проверяет версию сервера и обновляет её без создания копии на случайном адресе.

## Обновление

При открытии показан последний сохранённый снимок. Сверка запускается кнопками «Сверить с Codex» и «Проверить папки»; фонового наблюдения за файлами нет. Завершённая сверка появляется на открытой странице автоматически. Черновики заметок и открытая инструкция не сбрасываются.

Названия основных папок берутся из локального списка проектов Codex. Дополнительно добавленные папки сохраняют свои названия. Разные папки с одинаковым названием не объединяются. Список Codex читается локальным адаптером: при изменении его формата каталог сообщает об ограничении.

## Ограничения и сохранность

Каталог включает и отключает личные глобальные навыки, пользовательские MCP и плагины, подтверждённые приложения аккаунта. Для отдельных навыков доступны операции с файлами, описанные ниже; общего установщика всех типов надстроек нет. Он не меняет разрешения Codex. Обнаружение охватывает известные местные папки, настройки, доступный список приложений и отдельно переданные метаданные чата. Другие компьютеры и все чаты автоматически не проверяются. Программы отображаются только по явно указанным исполняемым файлам. Кеш плагина не подтверждает установку. Проверка наличия не запускает платные операции.

Исходники интерфейса остаются в `preview/` ради совместимости путей; эта папка теперь содержит **актуальную** редакцию. `app/manager/` — сохранённый интерфейс 2.0 и его вспомогательные модули. Личные записи текущей редакции находятся в `.local/catalog-current/`, исходные данные прежнего каталога — в `~/.codex/skill-catalog`. В Git не входят личные записи, снимки, ключи и конфигурация.

## Проверка разработки

`python -X utf8 -B -m unittest discover -s preview/tests`

`python -X utf8 -B -m unittest discover -s tests`

`npm --prefix preview ci` и `npm --prefix preview test` — проверки интерфейсной логики и безопасного чтения Markdown. Node.js требуется только для разработки, а не для запуска.

Исторические инструкции: `docs/legacy-v2/`. Возможности текущего выпуска описаны в [краткой инструкции](3-Возможности-и-ограничения.md).

Дополнительная проверка через настоящий Codex в одноразовой конфигурации: `python -X utf8 -B preview/tests/native_controls.py`. Она не запускает внешние сервисы.

## Сверка и файлы навыков (3.3)

- Сверка выполняется только по кнопкам «Сверить с Codex» и «Проверить папки». При запуске открывается последний снимок; фоновых проверок по расписанию нет.
- Проекты берутся исключительно из текущего реестра Codex. Удаление из Codex убирает запись каталога после успешной сверки; файлы, чаты и заметки не удаляются. При ошибке чтения сохраняется последний подтверждённый список с предупреждением.
- Недоступная папка помечается в меню проекта, его обзоре и настройках. Доступность повторно проверяется при сверке.
- «Найденные навыки» содержит найденные файлы без свежего подтверждения Codex. Из карточки можно прочитать инструкцию и подготовить установку в личную папку или зарегистрированный проект. Существующие папки не заменяются; основной список требует новой сверки Codex.
- «Удалить навык из Codex…» удаляет только выбранный файл `SKILL.md` после просмотра точного пути и подтверждения. Папка, скрипты, шаблоны, справочные материалы, вложенные навыки и другие установки сохраняются. Копия инструкции и запись операции находятся в `.local/catalog-current/removed-skills/`. В «Истории» есть восстановление исходного файла без замены существующего. В Windows выбранный файл блокируется от записи и замены, а удаление выполняется по открытому файловому дескриптору. Встроенные навыки, ссылки и части плагинов отдельно не удаляются.
- Установка и удаление не запускают инструкции навыка. Открытые чаты могут требовать перезапуска Codex. Для проверки результата нажмите «Сверить с Codex».


## Понятная справка и единый бэклог (3.4)

«Что здесь показано» содержит пять небольших разделов: начало работы, объяснение сущностей, проекты и области действия, использование каталога, заметки и история с пожеланиями. Подробности раскрываются по выбору; пути берутся из текущего снимка, ссылки ведут на официальные объяснения OpenAI.

«Пожелания» читают существующие карточки `Бэклог/BK-*.md` из папки документов, указанной в настройках установленного каталога. Сохранение создаёт карточку, строку в `Бэклог навыков.md` и событие истории. Комментарии, состояние и следующий шаг обновляют ту же запись; исходная формулировка сохраняется. Прежний интерфейс использует эти же документы. Изменения из Obsidian видны после «Обновить список».

Прежние пожелания из `annotations.json` переносятся при первом открытии раздела без повторных копий; исходный файл сохраняется. Если диск документов недоступен или карточку уже изменили в другом окне, форма сообщает об ошибке и сохраняет введённый текст. Запись идеи сама не запускает работу.
