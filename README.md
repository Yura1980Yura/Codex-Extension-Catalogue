# Skills-Catalogue

Личный браузерный каталог навыков, ресурсов и подключений Codex для Windows. Версия 2.0.0. Интерфейс работает на loopback-адресе этого компьютера; личные данные хранятся отдельно от программы.

## Что показывает каталог

- Навыки: направления задач, происхождение, авторы, теги, связанные ресурсы, установка, заметки и проверенные применения.
- Ресурсы: поставщик и возможность — например, Cloudflare, Meshy, PDF или Blender. Один ресурс может иметь несколько способов работы и подключений.
- Подключения: фактические записи MCP и приложения, обнаруженные через Codex. Компоненты расширений показаны внутри ресурсов и не считаются отдельными аккаунтами.
- Проекты: рекомендации ресурсов, подтверждённое использование через Codex и подтверждённые интеграции в код. Рекомендация сама по себе не меняет настройки.

Фильтры по направлению, происхождению, поставщику, типу, стоимости, тегам, способу работы и назначению проекту сочетаются независимо. Служебные возможности скрыты до выбора соответствующего условия. Боковые карточки содержат описание, сайт, возможности, инструкцию подключения, документацию, основания статуса и заметки.

## Установка и запуск

Требуются Windows, Python 3.12+ и установленный Codex. Сначала проверьте комплект: `python -X utf8 -B setup.py --verify-only`. Затем следуйте файлу «1-Начните-здесь.txt». Установщик первой установки не заменяет самостоятельно существующую изменённую программу; обновление установленной копии требует проверки контрольных сумм и сохранения пользовательских изменений.

Программа устанавливается в `~/Applications/Naviki`, данные — `~/.codex/skill-catalog`, навык — `~/.agents/skills/skill-catalog`, заметки — `~/Documents/Naviki/Projects/Catalog`. Повторный запуск выполняется через «Открыть каталог.cmd» в папке Naviki. Каталог не следует публиковать как сетевой сайт.

Репозиторий содержит исходники, справочники, шаблоны документов и тесты. Конфигурация Codex, OAuth, API-ключи, личные заметки, история пользователя и результаты генерации сюда не входят. При установке на другом компьютере подключения и авторизация выполняются отдельно.

## Модель данных и ограничения

Подробности: [организация ресурсов](app/skill-catalog/references/resources.md), [сохранность данных](app/skill-catalog/references/data.md), [возможности и ограничения](3-Возможности-и-ограничения.md).

Доступность в отдельном процессе Codex не доказывает доступность в уже открытом чате. Каталог сохраняет дату и основание проверки. Начальные связи ресурсов с проектами создаются как рекомендации. Для записи фактического использования требуется подтверждение и ссылка или путь к результату. Каталог не наблюдает автоматически за всеми чатами и кодом проектов.

Подключение и разрешение платных инструментов не поручают запускать генерацию. Meshy используется только по явной команде назвать именно Meshy; перед платной операцией согласуются задача, количество вариантов и лимит кредитов. API-ключ Meshy вводится пользователем только в локальной форме и хранится в Windows Credential Manager. Для Meshy сохраняется `default_tools_approval_mode="prompt"`.

## Проверка разработки

`python -X utf8 -B -m unittest discover -s tests`

`node --check app/manager/web/app.js`

`node --check app/manager/web/resources.js`

`node --check app/manager/web/projects.js`

Тесты выполняются во временных хранилищах, без платных вызовов и изменений живой конфигурации.
