# Каталог надстроек Codex

Разработчик: **55user3125**. Навык `skill-catalog` связывает чат Codex с локальным Codex Extension Catalogue.

## Для чего нужен

Показать имеющиеся навыки и надстройки, выбрать подходящие для задачи, выполнить явную сверку с Codex, прочитать карточку или пожелание. Состояние установки и включения определяется Codex и фактическими файлами, а личная организация хранится отдельно.

## Требования и установка

- Python **3.12+**, локальный Codex с `app-server` и браузер.
- Установочный ZIP каталога: [готовые выпуски](https://github.com/Yura1980Yura/Codex-Extension-Catalogue/releases/latest).
- Вставьте `START-CODEX.txt` из выпуска в локальный Codex. Установщик проверяет комплект, устанавливает программу и этот глобальный навык, создаёт ярлык.
- Сторонние Python-пакеты и npm для запуска каталога не требуются.
- Для автоматической проверки ссылок на дополнительно указанные GitHub-репозитории нужен GitHub CLI `gh` с доступом к этим репозиториям. Без него сохраняются ранее проверенные ссылки с датой; работа каталога продолжается.

Навык устанавливается в `~/.agents/skills/skill-catalog`. Пути программы, данных и выбранного профиля записаны в `installation.json` рядом с инструкцией. Установка не переписывает глобальный `AGENTS.md` и настройки подключений.

## Быстрый запуск

«Используй $skill-catalog: покажи состояние моего каталога, время последней сверки и доступные навыки для моей задачи».

При просьбе сверить сведения навык использует `scripts/client.py refresh`. Для просмотра доступны `status`, `list`, `show`, `wishes` и `wish` — без обязательной новой сверки.

## Документы, теги и обновление

Кнопка «Сверить с Codex» перечитывает зарегистрированные проекты, навыки и подключения, доступные документы внутри пакетов, метаданные вызовов и настроенные репозитории. Новые и удалённые документы обновляются в следующем снимке. Начальные теги определяются по назначению надстройки; ваши изменения сохраняются отдельно и имеют приоритет.

Инструкции, дополнительные документы, ссылки поставщика и вызовы собраны во вкладке «Документация». Реальные локальные файлы и действия с папками находятся в «Источниках».

Для обновления самой программы повторите установочный промпт из нового готового выпуска. Ярлык открывает установленную локальную версию.

## Ограничения

Сверка метаданных не запускает навыки и не проверяет платные операции. Отсутствующая папка проекта и неподтверждённый источник отмечаются явно. Открытые чаты могут сохранять прежние инструкции до перезапуска Codex.

Meshy используется только по отдельной явной команде с согласованными задачей, числом вариантов и лимитом кредитов. API-ключ вводится в локальную форму каталога, хранится в Windows Credential Manager и не передаётся в чат.
