Разверни Codex Extension Catalogue — каталог навыков, ресурсов, подключений и проектов Codex — на ЭТОЙ машине. Используй локальный Codex с доступом к её файловой системе.

Официальный репозиторий: https://github.com/Yura1980Yura/Codex-Extension-Catalogue
Готовые выпуски: https://github.com/Yura1980Yura/Codex-Extension-Catalogue/releases/latest
Архив: https://github.com/Yura1980Yura/Codex-Extension-Catalogue/releases/latest/download/Codex-Extension-Catalogue.zip
Контрольные суммы: https://github.com/Yura1980Yura/Codex-Extension-Catalogue/releases/latest/download/SHA256SUMS.txt

1. Если я передал ZIP рядом с этим текстом, используй его. Иначе выясни тег последнего стабильного Releases и скачай архив, START-CODEX.txt и SHA256SUMS.txt ИЗ ОДНОГО ЭТОГО ТЕГА (не смешивай разные latest во время выпуска). Рабочая ветка не заменяет готовый выпуск. Проверяй исходный адрес GitHub и версию. Сравни SHA-256 архива с SHA256SUMS.txt; сумма защищает целостность, а не доказывает независимую подлинность источника. Распакуй в новую временную папку, проверь пути файлов. Не используй личные данные автора.
2. Прочитай README.md, deployment.py и setup.py. Определи ОС, домашнюю папку, реальную папку рабочего стола (включая перенаправление OneDrive/XDG), действующий CODEX_HOME и исполняемый файл Codex. Нужен Python 3.12+; если его нет, подготовь установку из официального источника python.org/официального менеджера ОС и объясни мне необходимый шаг. Не отключай защиту ОС. Для чтения состояния нужен локальный Codex с поддержкой app-server; при отсутствии бинарника выясни его путь, не изображай успешную сверку.
3. Из распакованной папки запусти Python с -X utf8 -B: setup.py --verify-only, затем setup.py --plan. Покажи кратко точные пути программы, данных, навыка, заметок и ярлыка. Установка и создание ярлыка разрешены этим поручением; повторного подтверждения для обычной установки не требуется. Если установщик обнаружит чужие изменения или неуправляемую старую копию — сохрани её, изучи различия и согласуй только конфликтующую замену. Не удаляй старые данные, не переписывай AGENTS.md и конфигурацию подключений. Путь Codex при необходимости передай --codex-executable, пути папок --desktop-dir / --docs-dir.
4. Выполни setup.py. Новая установка размещает программу в ~/Applications/Codex-Extension-Catalogue, навык в ~/.agents/skills/skill-catalog, данные текущего профиля и ярлык «Codex Extension Catalogue» на рабочем столе. При обновлении ранее установленного 3.6.0 сохраняй его фактические пути из плана установщика. Пользовательские настройки и заметки сохраняются; старая версия программы при обновлении резервируется. Не копируй чужие навыки, чаты, ключи или историю из другой машины.
5. Прочитай установленный SKILL.md и используй $skill-catalog для первой явной сверки. Из УСТАНОВЛЕННОЙ папки выполни deployment.py check --refresh --open. Проверь реальный ответ локального /api/health, версию, завершение сверки, полноту доступных источников, зарегистрированные проекты, собственный skill-catalog и его путь. Если источник недоступен — укажи ограничение. Установленность навыка должна подтверждаться skills/list текущего профиля Codex, а не одним наличием файлов.
6. Проверь файл ярлыка и его цель, а на этой ОС — его фактический запуск. На macOS/Linux проверь доступность браузера/обработчика .app/.desktop; если окружение просит доверить ярлык, объясни этот шаг. Отдельно проверь, появился ли skill-catalog в новых доступных навыках Codex. Если текущий чат не перечитал навыки, предложи новый чат/перезапуск; не утверждай, что инструменты открытого чата уже изменились.
7. Итог: ссылка на локальный каталог, версия и тег выпуска, путь ярлыка, программы и навыка, какие проверки пройдены и оставшиеся ограничения. Происхождение каталога и собственного навыка должно отображаться Asemic. Обновления и сверка выполняются по команде пользователя, без фонового обновления по таймеру.

Установка не разрешает подключение сторонних сервисов и платную генерацию. Meshy — только по отдельной явной команде использовать Meshy, с согласованными задачей, числом вариантов и лимитом кредитов. Ключи не запрашивай в чате и не сохраняй в проекте; для Meshy предусмотрена локальная форма и Windows Credential Manager. Не меняй default_tools_approval_mode="prompt".
