НАВЫКИ — каталог Codex 3.0 · актуальная редакция 28.10.2026

1. Установите Codex и войдите в свой аккаунт.
2. Распакуйте весь комплект в обычную папку Windows.
3. Откройте эту папку в Codex. Вставьте текст из «2-Промпт-для-Codex.txt».
4. После установки открывайте «Документы\Naviki\Открыть каталог.cmd».

Из исходников на компьютере с Python 3.12+ можно сразу выполнить:
python -X utf8 -B launch.py

Слева выбирайте «Весь Codex» или проект. Нажмите карточку, чтобы понять,
для чего нужна надстройка, что в неё входит и где она установлена.
Фильтры сочетаются; в выпадающих списках можно поставить несколько галочек.
Свои заметки и порядок карточек сохраняются на вашем компьютере.
Прежняя редакция доступна по одной ссылке внизу боковой панели.

Полное описание — README.md и «3-Возможности-и-ограничения.md».
Это местный каталог; адрес 127.0.0.1 не открывает его у другого человека.
Каждый пользователь получает свой список и подключает свои аккаунты.
